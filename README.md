# Plataforma ORION

"Inteligência Artificial potencializando o conhecimento humano."

A Plataforma ORION é um ecossistema inteligente de saúde que integra pacientes, profissionais de saúde, clínicas, hospitais, laboratórios e serviços digitais por meio de Inteligência Artificial, promovendo uma experiência segura, eficiente e centrada nas pessoas.
